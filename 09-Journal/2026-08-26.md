# Tarevo Journal - 2026-08-26

## Contexto

Se completo y valido en produccion la primera arquitectura de impresion silenciosa de Tarevo POS sobre Windows.

El objetivo fue permitir que Tarevo imprima directamente desde el POS web sin depender de `window.print()` ni del dialogo de impresion del navegador.

## Resultado validado

Se comprobo el flujo real:

```text
Tarevo POS en Chrome
   -> QZ Tray 2.2.6
   -> firma SHA512 desde backend Tarevo
   -> certificado publico Tarevo confiado localmente
   -> impresora Windows
```

La prueba final imprimio correctamente sin mostrar la ventana repetitiva `Allow` de QZ.

La primera impresora usada para la prueba fue una HP Smart Tank 710-720. La impresion confirmo la comunicacion completa, aunque el contenido pensado para ticket puede verse recortado por margenes fisicos de una impresora A4. Se decidio incorporar margenes configurables y vista previa en una siguiente fase.

### PR #161

Se endurecio la carga de la clave privada.

Se detecto que Coolify entregaba `QZ_PRIVATE_KEY_B64` con exactamente un `=` inicial accidental dentro del contenedor. El backend normaliza solo ese caso y valida despues base64, PEM y clave RSA con OpenSSL.

La clave privada nunca se expone al frontend ni se guarda en GitHub.

## Preferencias locales

Las preferencias actuales se guardan en:

```text
localStorage["tarevo_pos_printing_preferences:<tenant>"]
```

La decision es intencional: cada computador puede usar impresoras diferentes aunque pertenezca a la misma empresa.

## Decision Windows

Se aprobo crear `Tarevo Print Connector` como experiencia visible para el cliente.

Objetivo:

```text
TarevoPrintConnector.exe
```

Debe instalar/configurar QZ Tray, certificado publico Tarevo, arranque automatico y verificacion, sin incluir ningun secreto de backend.

El POS debe ofrecer descarga autoservicio desde `Configuracion > Impresion`, evitando que un cliente dependa de soporte tecnico para instalar un nuevo computador.

## Decision macOS

macOS usara la misma arquitectura QZ que Windows.

Objetivo:

```text
TarevoPrintConnector.pkg
```

Se preve firma/notarizacion con Apple Developer ID para distribucion profesional cuando corresponda.

## Decision Android

Android no usara QZ Tray.

Para terminales POS Android con impresora integrada se aprobo la direccion:

```text
Tarevo POS App
   -> WebView de pos.gettarevo.com
   -> bridge nativo seguro
   -> SDK/servicio de impresora del fabricante
```

El POS web seguira siendo la fuente de verdad. Una actualizacion normal de la web no requiere nueva APK; solo los cambios de la capa nativa/hardware requieren nueva version Android.

La arquitectura debe permitir adaptadores por fabricante, por ejemplo Sunmi, iMin, PAX o ESC/POS generico cuando aplique.

## Ticket - siguiente pulido
